Lofi Longform Uploader — プライバシーポリシー

最終更新日: 2026年8月5日

「Lofi Longform Uploader」（以下「本ツール」）は、運営者本人が自分の YouTube チャンネルへ 自作の長尺BGM動画を投稿するために使用する、非公開のコマンドラインツールです。 一般に配布・公開しておらず、運営者以外の利用者はいません。

取り扱う情報

  • 本ツールは YouTube Data API v3 を利用し、運営者本人の YouTube アカウントにのみアクセスします。
  • アクセスには Google の OAuth 2.0 を使用し、以下のスコープのみを要求します。
    • youtube.upload — 動画のアップロード
    • youtube — サムネイルの設定、および本人の再生リストへの追加
  • 他のユーザー、他のチャンネル、視聴者に関する情報は一切取得しません。
  • 視聴回数などの分析データ（YouTube Analytics）は取得しません。

保存する情報と保存場所

  • OAuth のアクセストークンおよびリフレッシュトークンを、運営者本人の PC 内にのみ保存します。
  • アップロード完了後、動画 ID と動画 URL を同じ PC 内のファイルに記録します。
  • これらを外部サーバーへ送信・保管することはありません。

第三者への提供

取得した情報を第三者へ提供・販売・共有することはありません。 広告配信、行動分析、プロファイリングにも使用しません。

アクセスの取り消し

本ツールに付与した権限は、Google アカウントの「サードパーティ製のアプリとサービス」 からいつでも取り消せます。取り消し後、本ツールは YouTube アカウントへアクセスできなくなります。 また、PC 内に保存されたトークンファイルを削除することでも同様にアクセスは無効になります。

データの削除

  • 本ツールが保持するデータは、PC 内のトークンファイル（token_*.json）と、 動画 ID・URL を記録したファイル（uploaded.json）のみです。
  • これらのファイルを削除すれば、保持しているデータはすべて消去されます。外部に複製は存在しません。
  • YouTube から取得した情報を 30 日を超えて保存することはありません （保存しているのは上記の動画 ID・URL のみで、これは運営者自身の投稿記録です）。
  • 削除に関するご要望は ueda123g@gmail.com までご連絡ください。

YouTube API サービスの利用について

本ツールは YouTube API サービスを利用しています。本ツールを使用することは、 YouTube 利用規約に同意することを意味します。 Google のプライバシーポリシーは https://policies.google.com/privacy をご確認ください。

準拠

本ツールは YouTube 利用規約、 YouTube API サービス デベロッパー ポリシー、 および Google プライバシー ポリシーに従って運用します。

Lofi Longform Uploader — Privacy Policy

Last updated: August 5, 2026

"Lofi Longform Uploader" (the "Tool") is a private command-line utility used by its owner to upload their own long-form background-music videos to their own YouTube channels. It is not distributed or publicly available, and it has no users other than the owner.

Information the Tool accesses

  • The Tool uses the YouTube Data API v3 and accesses only the owner's own YouTube account.
  • Access is authorized through Google OAuth 2.0, requesting only these scopes:
    • youtube.upload — uploading videos
    • youtube — setting the custom thumbnail and adding the video to the owner's own playlist
  • No information about other users, other channels, or viewers is collected.
  • No analytics data (YouTube Analytics) is retrieved.

Information stored, and where

  • OAuth access and refresh tokens are stored only on the owner's own computer.
  • After an upload, the video ID and URL are written to a local file on the same computer.
  • None of this is transmitted to or stored on any external server.

Sharing with third parties

No information obtained through the API is sold, shared, or otherwise disclosed to third parties. It is not used for advertising, behavioral analysis, or profiling.

Revoking access

Access granted to the Tool can be revoked at any time from Google Account → Third-party apps & services. Deleting the locally stored token file has the same effect.

Data deletion

  • The only data the Tool retains are the local token files (token_*.json) and a file recording the video ID and URL of each upload (uploaded.json).
  • Deleting those files erases everything the Tool holds. No copies exist anywhere else.
  • No information obtained from YouTube is stored for more than 30 days, other than the owner's own video IDs and URLs described above.
  • Deletion requests can be sent to ueda123g@gmail.com.

YouTube API Services

This Tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's Privacy Policy is available at https://policies.google.com/privacy.

Compliance

The Tool is operated in accordance with the YouTube Terms of Service, the YouTube API Services Developer Policies, and the Google Privacy Policy.
