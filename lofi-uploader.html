Lofi Longform Uploader

個人運営の YouTube チャンネル向け 長尺BGM動画アップロードツール

本ツールは、運営者（上田瑞起）が自分の YouTube チャンネルへ、自作の長尺BGM動画（3〜4時間）を 投稿するために使用する非公開のコマンドラインツールです。一般に配布・公開しておらず、 運営者以外の利用者はいません。

対象チャンネル

Tokyo Rainy — https://www.youtube.com/@tokyorainymusic Lofi with Latte — https://www.youtube.com/@Lofi-with-Latte

動画に使用しているイラスト・映像・楽曲はすべて運営者が制作したものです。

機能

  • 完成した動画ファイルを、運営者自身のチャンネルへアップロードする（videos.insert）
  • その動画用に用意したカスタムサムネイルを設定する（thumbnails.set）
  • 運営者自身の再生リストを名前で検索し（playlists.list）、動画を追加する（playlistItems.insert）

上記以外の API は呼び出しません。他のユーザー、他のチャンネル、視聴者に関する情報は取得しません。

YouTube API サービスの利用

本ツールは YouTube API サービスを利用しています。 認証には Google の OAuth 2.0 を使用し、運営者本人のアカウントにのみアクセスします。 本ツールの利用にあたっては YouTube 利用規約および Google プライバシー ポリシーが適用されます。

Lofi Longform Uploader

A private uploader for long-form background-music videos

This is a private command-line tool used by its owner (Mizuki Ueda) to upload their own long-form (3–4 hour) background-music videos to their own YouTube channels. It is not distributed or publicly available, and it has no users other than the owner.

Channels

Tokyo Rainy — https://www.youtube.com/@tokyorainymusic Lofi with Latte — https://www.youtube.com/@Lofi-with-Latte

All artwork, animation and music in the videos are created by the owner.

What it does

  • Uploads a finished video file to the owner's own channel (videos.insert)
  • Sets the custom thumbnail made for that video (thumbnails.set)
  • Looks up one of the owner's own playlists by title (playlists.list) and adds the video to it (playlistItems.insert)

No other API endpoints are called. No information about other users, other channels or viewers is collected.

YouTube API Services

This Tool uses YouTube API Services. Authentication is performed with Google OAuth 2.0 and accesses only the owner's own account. Use of the Tool is subject to the YouTube Terms of Service and the Google Privacy Policy.
